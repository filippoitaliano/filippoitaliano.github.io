# garden.filippoitaliano.com

My dynamic website from scratch.

## Repository artifacts

The isometric icons in the articles bar live in `client/artifacts` and link to my public
repos. The site logo (`client/logo.svg`) and the favicon (`client/favicon.svg`) are the
artifact of this repo — the garden plot — kept as their own files so they can be reworked
without touching the articles bar. Everything is generated by
`python3 tools/generate-artifacts.py client`.

## Social preview

Shared links show the card in `client/og-image.png` (1200x630), declared with Open Graph
and Twitter meta tags in `index.html` and in `404.html` — the latter matters because
GitHub Pages serves it for deep links like `/article/<id>`, and crawlers never run the
bookmark redirect. Regenerate the card with `python3 tools/generate-og-image.py client`
(needs `pip install playwright`); edit the copy and layout inside that script.

## Run in development mode

1. Edit the API address in client/app.js to use this address: http://localhost:8082/articles.
2. Edit the ALLOWED_ORIGINS constant in server/app.js to include http://localhost:8080.
3. Run `npx http-server` in the root to host the frontend on `localhost:8080`.
4. Change directory to server dir and run `npm start`.

## Production

- Frontend: GitHub Pages on `garden.filippoitaliano.com` (see the CNAME file).
- Backend: Render, `https://filippoitaliano-github-io.onrender.com` — root directory `server`, start command `npm start`.
